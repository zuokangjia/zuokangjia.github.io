入门笔记，跟着教程过一遍，只记自己觉得要留意的。

Python 是什么

解释型语言，写完直接跑，不用先编译。跟 C、Java 比最直观的区别是没有大括号，靠缩进分代码块，我一开始最不习惯的就是这个。

第一个程序

缩进

Python 的代码块不用 {}，用缩进表示。同一层的缩进必须完全一致，一般用四个空格；Tab 和空格混着用最容易报 IndentationError。

变量

不用提前声明类型，赋值的时候就创建了：

等号左边是变量名，右边是值。变量必须赋值之后才能用。

运算符

分几类记：

  • 算术：+、-、*、/、%（取余）、**（幂）、//（取整除）
  • 赋值：=
  • 比较：==、!=、>、<、>=、<=
  • 逻辑：and、or、not

注释

单行注释用 #。三个引号括一段也能当多行注释用，不过它本质上是字符串。

分支结构

三种写法：if、if-else、if-elif-else。

Python 3.10 之后还有 match-case，入门先不管它。
